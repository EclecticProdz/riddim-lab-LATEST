# Riddim Lab — development roadmap

Branding in this source has been updated to **Riddim Lab — The Complete Reggae Production Suite by Eclectic Prodz**.

## Current change in this development pass
- Preserves the existing delay engine and its parameters.
- Adds a first tape-colour stage to the incoming signal: adjustable saturation, tone softening, wear and subtle wow/flutter.
- Adds selectable low-pass/high-pass mode to the existing feedback filter.
- Updates product metadata and the Actions artifact name.

## Not yet implemented in this pass
The following require dedicated DSP, user controls, and listening/build tests before they should be described as finished:
- Fully controllable tape module UI and dedicated ten-preset bank
- Standalone Tubby filter module and its ten presets
- Expanded tempo-synced echo options and ten presets
- Spring reverb DSP and ten presets
- Plate reverb DSP and ten presets
- Final tabbed interface and preset browser

Do not treat the roadmap as evidence that these modules are implemented. Build and test this intermediate source in GitHub Actions and Ableton before proceeding.
